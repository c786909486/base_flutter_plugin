# 安装指南

## 方法一：从 VSIX 文件安装

1. 下载 `base-flutter-generator-1.0.0.vsix` 文件
2. 打开 VSCode
3. 按 `Cmd+Shift+P`（Mac）或 `Ctrl+Shift+P`（Windows）
4. 输入 "Install from VSIX"
5. 选择下载的 `.vsix` 文件

## 方法二：从扩展视图安装

1. 在 VSCode 中打开扩展视图（`Cmd+Shift+X`）
2. 点击右上角的 "..." 菜单
3. 选择 "Install from VSIX..."
4. 选择 `base-flutter-generator-1.0.0.vsix` 文件

## 使用方法

1. 在文件栏中右键点击任意文件或文件夹
2. 选择 "[Base] New Page"
3. 按照提示输入页面名称、ViewModel 名称
4. 选择 ViewModel 类型和页面类型
5. 自动生成两个文件

## 快捷键

目前没有设置快捷键，可以通过右键菜单使用。

## 卸载

1. 打开 VSCode 扩展视图
2. 找到 "Base Flutter Generator"
3. 点击 "卸载" 按钮
